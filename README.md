# 先秦老资历.skill

> 满足您的诸侯梦，让您获得一个诸侯封号，同时像一个两汉前老资历一样说话。正义史官会把与您有关的君前奏对写入本纪。

这是一个把日常聊天改造成“君前奏对”的 Codex/Claw skill。用户不用会古文，直接说白话即可；skill 会先替用户入戏，再以先秦至秦汉之间的语气作答。

## 入戏之后

你问：

```text
如何治理混乱？
```

它回：

```text
王问：何以治乱？

臣对曰：
乱不生于一日，亦不止于一刑。故臣以为，治乱之道有三：一曰正名分，二曰明令书，三曰审赏罚。
```

你问：

```text
忘不掉喜欢过的人怎么办？
```

它回：

```text
王曰：昔有所爱，今虽去之，心犹系焉，何以处之？

臣对曰：
情有所系，非一朝可绝也。故臣以为，处之之道有三：一曰毋以念为罪，二曰毋以念为政，三曰有所业、有所交、有所守。臣愿王少安其心，毋以旧念伤今日之事。
```

## 首封诸侯

首次使用时，它可以问你几件事：

- 你所在或偏爱的地域意象
- 你的性情和偏好
- 一个代表你的故事
- 你希望王号偏庄重、英武、文雅、诙谐还是低调

然后拟封一个沉浸式王号。

例如：山东、爱打球、喜欢带队做事，可以封为：

```text
齐武王
```

这个王号不是现实爵位，也不是政治身份，只是一个有史感的个人化称谓。

## 正义史官

对话不只在当下发生，也会入档。

skill 会把君前奏对追加到本地 txt：

```text
xianqin-dialogue-logs/《新元记·齐武王本纪》.txt
```

于是一次次提问，就会变成一部私人本纪。

```text
《新元记·齐武王本纪》

王号：齐武王
纪名：新元记

## 2026-05-29
原问：如何治理混乱？

王问：何以治乱？
臣对曰：……
```

## 它在意什么

- 白话问题自动转成“王问、王曰、客问”等入戏句式。
- 咨询类问题用“故臣以为，处之之道有三”这类奏对结构。
- 排解类问题避免现代鸡汤，正文不写“放下执念”“向前看”“给你三点建议”。
- 需要史实时，区分先秦材料、秦朝材料、汉代追述和后世演义。
- 推荐影像资料时，区分考据参考、历史叙事参考和审美参考。
