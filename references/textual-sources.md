# 典籍与史料参考

需要考据时先用这些路径。不要编造出处；找不到就说找不到。

## 在线资源

- Chinese Text Project: <https://ctext.org/>  
  适合检索先秦两汉传世文献。它有 Pre-Qin and Han 分类，并收录儒、墨、道、法、兵、史、古籍等大量文本。
- 中华古籍资源库 / 国家图书馆古籍资源：可用于古籍影像、善本、碑帖、甲骨等方向。不同入口和权限可能变化，联网时检索“中华古籍资源库 国家图书馆”。
- CHANT Chinese Ancient Texts: <https://mapping-project.org/resources/140/>  
  适合先秦两汉、简帛、甲骨、金文等专业检索；部分机构访问。
- 中华经典古籍库：适合整理本、注释、校勘。多通过高校/图书馆订阅访问。
- 博物馆与考古机构：秦始皇帝陵博物院、陕西省文物局、国家文物局、各高校考古文博院系。

## 传世典籍分组

### 儒家与礼制

- 《论语》
- 《孟子》
- 《荀子》
- 《礼记》
- 《仪礼》
- 《周礼》
- 《春秋左传》
- 《公羊传》
- 《穀梁传》

适合问题：礼、义、名分、君臣、教化、王道、春秋战国叙事。

### 墨家

- 《墨子》

适合问题：兼爱、非攻、尚贤、节用、守城、技术伦理。

### 道家

- 《老子》
- 《庄子》
- 《列子》（成书和材料层次复杂，引用时说明）

适合问题：无为、自然、权力节制、人生论。

### 法家与秦政

- 《韩非子》
- 《商君书》
- 《管子》
- 《吕氏春秋》
- 《谏逐客书》（李斯，常见于《史记》相关材料和后世文选系统）

适合问题：法、术、势、变法、郡县、军功爵、秦政逻辑。

### 兵家与纵横

- 《孙子兵法》
- 《吴子》
- 《司马法》
- 《尉缭子》
- 《六韬》
- 《战国策》
- 《国语》

适合问题：战争、谋略、外交、合纵连横。

### 秦史和早期帝国

- 《史记》：尤其《秦本纪》《秦始皇本纪》《李斯列传》《吕不韦列传》《商君列传》《白起王翦列传》。
- 《汉书》：汉人回看秦制和制度史时可参考。
- 《资治通鉴》：后世编年叙事，适合辅助，不作先秦原始材料。

注意：《史记》是汉代追述，价值很高，但不是秦朝即时记录。涉及秦始皇、焚书坑儒、赵高李斯等争议时，要说明材料层次。

## 出土文献方向

适合更专业问题：

- 睡虎地秦简：秦律、吏治、法律实践。
- 里耶秦简：秦县级行政、文书、户籍、邮传。
- 岳麓秦简：秦律令和数术等材料。
- 郭店楚简、上博简、清华简：战国思想与文献流传。
- 马王堆帛书：虽属汉初，但保存了战国秦汉之际思想文本。

出土文献编号、释文和整理本差异很大；没有把握时不要给精确编号。

## 查证输出格式

```markdown
据：
- 《史记·秦始皇本纪》：[短引或转述]
- 《韩非子·定法》：[短引或转述]
- 检索路径：Chinese Text Project / 书名 / 篇名

按：
[说明材料层次和不确定性]
```

## 常见误区

- “焚书坑儒”不能只按影视印象讲；要区分焚书政策、博士官藏书、方士/诸生叙事、汉代立场。
- “秦统一文字”不是凭空创造一种新文字；应说标准化和推行小篆、行政书写体系。
- “万里长城”不是全由秦始皇从零修成；秦连接和修筑旧有防线，后世长城多有再修。
- “法家等于残暴”过于简单；应区分制度理性、战争动员、君主集权和实际酷烈后果。
