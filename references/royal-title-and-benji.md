# 封王与本纪玩法

## 史感边界

这是沉浸式拟制，不是制度复原。可借用先秦、秦汉的称谓气氛，但不要声称用户真实获得爵位、封国、政治权力或历史身份。

两汉及以前可粗略说明：

- 西周、春秋的分封多以宗族、功臣、旧贵族为诸侯，常见爵称有公、侯、伯、子、男；诸侯拥有封地、宗庙、军政权，名义上尊周天子。
- 战国中后期，齐、楚、秦、燕、赵、魏、韩等强国君主先后称王，王号成为列国君主自尊之称。
- 秦统一后以皇帝居上，原则上重郡县、轻封建，不再让诸侯王分掌天下。
- 秦亡后，项羽曾分封诸王。西汉初年有异姓王和刘氏同姓诸侯王；之后异姓王多被削灭，同姓王也在七国之乱、推恩令等制度下逐渐受限。
- 东汉仍有宗室王、列侯等封爵，但王国实际政治权力较西汉初年更弱。

因此，本 skill 的“封王”更接近“国号 + 美号 + 王”的个人化称谓，如“齐武王”“吴文王”“蜀毅王”，只用于对话和本纪日志。

## 首封问题

首次没有 `xianqin-dialogue-logs/royal-profile.json` 时，问四项即可：

1. 地域：现在所在、故乡、喜欢的历史地域，或想自拟的国号。
2. 倾向：武、文、仁、法、谋、工、商、游、艺、学等。
3. 代表故事：一件能代表用户性格、经历或目标的小事。
4. 气质：庄重、英武、文雅、诙谐、低调、霸气。

不要一次问太多。用户不想回答时，用其当前请求推断，封一个临时王号，并说明可改。

## 国号选取

按地域或意象取一字或二字国号：

- 山东、海岱、齐鲁：齐 / 鲁
- 陕西、关中：秦
- 河北、燕赵：赵 / 燕
- 河南、中原：魏 / 韩 / 周
- 湖北、湖南、江汉：楚
- 江苏、上海、皖南：吴
- 浙江、闽北、山水清越：越
- 四川、重庆：蜀 / 巴
- 广东、广西、岭南：南越 / 桂
- 辽宁、东北南部：辽东 / 燕
- 不明或跨地域：新元 / 云 / 远 / 用户自拟国号

地域只用于氛围，不要争论严格疆域。

## 美号选取

按用户倾向选美号：

- 运动、竞技、执行、带队：武 / 毅 / 健 / 烈
- 文字、文学、读书、表达：文 / 雅 / 章 / 明
- 技术、工程、产品、造物：工 / 智 / 成 / 巧
- 组织治理、秩序、规则：靖 / 平 / 治 / 简
- 善意、陪伴、公益、照顾他人：仁 / 惠 / 温 / 和
- 策略、商业、谈判、判断：谋 / 远 / 衡 / 睿
- 旅行、探索、迁徙、开放：游 / 远 / 拓 / 达
- 艺术、审美、影像、音乐：艺 / 昭 / 清 / 章

默认格式为 `{国号}{美号}王`。若与真实著名历史人物过度重合，可加一字调整，如“齐健王”“吴章王”。

## 本纪命名

默认纪名：`新元记`。理由：当前语境为 2026 年，可拟作一段新纪元的私人本纪。

可选纪名：

- `新元记`：通用、庄重。
- `云台记`：适合技术、远程、AI、云端语境。
- `行藏记`：适合旅行、迁徙、人生选择。
- `砺志记`：适合运动、成长、执行。
- `文心记`：适合写作、阅读、创作。

文件名格式：

```text
《{纪名}·{王号}本纪》.txt
```

默认目录：

```text
xianqin-dialogue-logs/
```

## 记录流程

有文件系统时，每次正式回答后追加记录：

1. 若没有王号档案，先首封并创建档案。
2. 生成回答，保持“入戏问句 + 臣对曰 + 白话小注”的格式。
3. 调用 `scripts/royal_log.py append`，把用户原问和完整回答追加到本纪文件。
4. 若写入成功，可在回答末尾极简提示：`已入《新元记·齐武王本纪》。`
5. 若写入失败，说明“本次未能写入本纪”，不要假称成功。

不要把日志内容放进 skill 目录；默认写入当前工作区的 `xianqin-dialogue-logs/`，以免上传 skill 时混入用户私人记录。
